# Security Policy

The Universal Code is a set of ethical principles and supporting documentation. It is not executable software and does not process data, run agents, or expose runtime surfaces.

## Reporting a concern

If you believe there is a security-relevant issue with this repository itself (for example, compromised credentials, malicious content injected into the files, or a problem with the GitHub organization), please report it privately to:

**security@monkeyking.dev**

You may also open a Discussion in the repository if the concern does not require confidentiality.

## Scope

This policy covers only the contents and hosting of this repository.  
It does not cover downstream systems, agents, or applications that choose to implement or reference the Universal Code.

## Preferred contact

For sensitive reports, email **security@monkeyking.dev**.
