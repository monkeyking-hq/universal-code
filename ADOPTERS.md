# Adopters

Projects and organizations that reference or follow the Universal Code.

This list is **voluntary** and maintained by pull request. Listing here means you use or pin the Code; it is **not** a certification, audit, or compliance claim.

## Add yourself

1. Open a PR that adds a row to the table below (keep alphabetical by name when practical).
2. Use the columns as specified. Leave optional cells blank if you prefer.
3. Pin a real version (for example `1.0.0`). Prefer a versioned public URL, a vendored copy, or a commit-pinned link - see [GETTING-STARTED.md](GETTING-STARTED.md).
